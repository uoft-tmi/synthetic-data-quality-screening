# synthetic-data-quality-screening

## Overview

Synthetic data, meaning data generated by a model such as an LLM instead of collected from the real world, is cheap and fast to produce. Its quality varies, though. Some examples are wrong, repetitive, biased or toxic, and a model fine-tuned on them learns from all of it.

This project asks one question: **which filtering method keeps the good synthetic examples and removes the bad ones?**

## Approach

Every team member runs the same pipeline and changes only the filtering step, so the methods can be compared fairly.

1. **Generate** synthetic data
2. **Filter** it with a chosen method
3. **Fine-tune** a model on the filtered data
4. **Evaluate** the model
5. **Compare** the methods

## Filtering methods

| # | Method | Core idea | Example papers |
|---|--------|-----------|----------------|
| 1 | LLM-as-a-Judge | An LLM scores each example against a rubric, and low scorers are removed | [AlpaGasus](https://arxiv.org/abs/2307.08701), [QuRating](https://arxiv.org/abs/2402.09739), [Instruction Mining](https://arxiv.org/abs/2307.06290), [Orthogonal Rules](https://arxiv.org/abs/2410.04715) |
| 2 | Uncertainty-aware filtering | Measures how confident a model is in its quality ratings, using token, sentence and model-level uncertainty | [SelectIT](https://arxiv.org/abs/2402.16705), [GradFiltering](https://arxiv.org/abs/2601.13697) |
| 3 | Shapley-based filtering | Estimates each example's contribution to model performance using Shapley values | [Data Shapley](https://icml.cc/virtual/2019/oral/4390), [Beta Shapley](https://arxiv.org/abs/2110.14049), [SHED](https://arxiv.org/abs/2405.00705) |
| 4 | Multi-dimensional quality assessment | Scores several dimensions at once, such as quality, complexity and diversity | [DEITA](https://arxiv.org/abs/2312.15685), [QDIT](https://arxiv.org/abs/2311.14736), [MIG](https://arxiv.org/abs/2504.13835) |
| 5 | Difficulty-based filtering | Keeps examples in a useful difficulty range, using signals like the Instruction-Following Difficulty (IFD) score | [Cherry LLM / IFD](https://arxiv.org/abs/2308.12032), [Superfiltering](https://arxiv.org/abs/2402.00530) |
| 6 | Bilevel filtering | Jointly optimizes the data selector and the downstream model | [SEAL](https://arxiv.org/abs/2410.07471), [ScaleBiO](https://arxiv.org/abs/2406.19976) |
